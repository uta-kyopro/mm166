# seed 1〜100 構造診断

最新ソルバーの最終盤面をseed 1〜100で計測した。実行は4並列、失敗0件、`mean(log10(score)) = 5.127289`。生データは `structure_diagnostics_seed1_100.csv` に保存した。

## 指標

- 接続率: `k / P`
- 全ボーナス幹線長率: 全ボーナスを踏むマッチ経路の合計長 `H / (3V)`
- マッチ線分利用率: 全マッチ経路の合計長 `/ (3V)`
- ボーナス利用率: 全マッチ経路のボーナス利用数 `/ (3B)`
- 回転罰比: `Mm / t`
- 10%改善必要幹線長: `k` と回転数が同じと仮定した `0.1Q / (B+1)`

## 結論

第一の不足は接続数である。平均接続率は80.4%で、26ケースが75%未満だった。`Q`を維持できると仮定すれば、100ケース中90ケースは未接続ペアを必要本数だけ追加することで10%以上改善できる余地がある。

第二の不足はボーナス線分の共有である。平均利用率は73.5%で、26ケースが60%未満だった。一方、マッチ線分利用率は平均93.5%と高く、90%未満は11ケースだけである。したがって大半の盤面では空き線分や内部ループを単純に回収するだけでは足りない。すでに低ボーナス経路が使っている線分を全ボーナス幹線へ移し、取り除いたペアを外周の短路で再接続する必要がある。

特にseed 4, 11, 25, 26, 30, 37, 43, 49, 57, 70, 72, 92, 93は、マッチ線分利用率94%以上なのにボーナス利用率60%未満である。これは「線分不足」ではなく「線分配分の失敗」を直接示す。

回転罰は全体では第三要因だが、小盤面では支配的になる。`Mm/t > 0.2` は17ケースあり、seed 95, 76, 1, 88, 51, 58では特に大きい。これらは幹線延長より、接続を維持した回転削減や少数の短経路追加が効きやすい。

## 次の探索設計

1. 全ボーナス幹線を2〜3本選び、各ボーナスタイルの3線分を先に割り当てる。
2. タイル回転domainを共有制約として持ち、複数幹線の現在ポートを同時に進める。
3. 幹線候補が使いたい線分上の低ボーナス経路を一時的に除去し、幹線完成後に除去ペアを外周最短路で再接続する。
4. 採否は代理的な集中度ではなく、再接続後の真スコア `k(t-Mm)` で決める。

現在の盤面は線分総量の回収自体はかなり進んでいる。10%以上を狙う中心課題は、新しい線分を探すことではなく、既存線分を「短い多数の接続」と「2〜3本の全ボーナス幹線」へ再配分することである。
